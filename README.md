# Papertrail Bookshop

A responsive independent-bookshop storefront built with Vite and vanilla JavaScript. Browse a curated catalog, search by title or author, filter and sort shelves, save favourites, and manage a persistent shopping bag.

## Run locally

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. Create a production build with `npm run build`.

Book covers are loaded from Open Library Covers. Cart and saved-book selections persist in the browser. Checkout is a front-end demo and does not collect payment.
